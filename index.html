Architecture

XPURL fuses a character-level DistilBERT encoder with a 25-dimensional statistical feature head. Both streams are concatenated and passed through a shared classifier.

Continual Learning

Elastic Weight Consolidation (EWC) allows the model to adapt to new phishing patterns without forgetting previous knowledge — protecting against concept drift in live deployments.

Explainability

Every prediction is accompanied by SHAP values showing which URL features drove the decision — enabling analysts to understand, audit, and trust the system.

Backend

Connect the HTML file to app.py. Set XPURL_MODEL_DIR to your saved model directory. The server runs on localhost:5000 by default. If no model is found, the app runs in demo mode using heuristic scoring.
